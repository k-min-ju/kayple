# 과제 명세: 상담 예약 웹 서비스 (1시간)

> 원문 안내 페이지 요약. 키 다운로드 링크·안내 페이지 URL은 공개 저장소라 제외함.

## 만들 것
1시간짜리 1:1 상담 예약. 상담실이 하나라 한 시간대에 예약 한 건만 받는다.

## 기능 (수용 기준)
1. 날짜를 고르면 예약 가능 시간이 보인다. 날짜는 오늘부터 7일, 시간은 10·11·13·14·15·16·17시(12시 점심). 예약된 시간은 '마감' 표시.
2. 이름·연락처로 예약. 입력값이 잘못되면 오류 메시지.
3. 같은 시간 중복 예약은 서버에서 막고, 화면에 오류 메시지("이미 예약된 시간입니다. 다른 시간을 선택해 주세요.").
4. 연락처로 내 예약 조회·취소.
5. /admin 에서 날짜별 예약 목록. 아이디·비밀번호 로그인 필수, 비로그인 시 관리자 API도 응답하지 않음. 계정 1개, 비밀번호는 코드·GitHub에 넣지 않고 서버에서 설정 → 제출 메모 칸에 기재.
6. 중복 예약 방지 같은 핵심 기능에 테스트 코드.
7. https://kmj.recruit.kayple.com 에서 실제 동작.

## 기술 조건
- 웹: React 또는 Next.js / 백엔드: Spring Boot / DB: 서버에 설치된 MySQL 8.0

## 화면 시안 (10개, 최대한 따르되 디자인 디테일은 평가 대상 아님)
1 예약하기(날짜·시간 선택) · 2 예약 정보 입력 · 2-1 입력 오류 · 3 예약 완료(예약번호, 연락처 마스킹 010-****-5678) ·
4 내 예약 확인(예약됨/취소됨 배지, 취소 버튼) · 4-1 빈 결과 · 4-2 취소 확인 모달 ·
5 관리자 로그인 · 5-1 로그인 오류("아이디 또는 비밀번호가 올바르지 않습니다") · 5-2 관리자 예약 목록(시간·이름·연락처·상태·예약 일시, 날짜 드롭다운, 로그아웃)
